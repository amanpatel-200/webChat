# 💬 SafeTalk(WebChat Application)

A modern real-time chat application built with the MERN Stack that enables users to communicate instantly through a secure and responsive interface.

## 🚀 Features

- 🔐 Secure User Authentication (JWT)
- 💬 Real-Time One-to-One Chat
- 🟢 Online/Offline User Status
- ⚡ Instant Message Delivery using Socket.io
- 🔒 Encrypted Messaging Support
- 🖼️ Image Sharing via Cloudinary
- 📱 Responsive UI
- 🌙 Clean Chat Interface
- 🍪 Cookie-based Authentication
- ⚡ Fast React + Vite Frontend

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/amanpatel-200/webchat.git
```

```bash
cd webchat
```

---

## Install Client

```bash
cd Client
npm install
npm run dev
```

---

## Install Server

```bash
cd server
npm install
npm run dev
```

---

## 🔑 Environment Variables

Create a `.env` file inside the **server** folder.

```env
PORT=5000

MONGO_URI=your_mongodb_connection

JWT_SECRET=your_secret_key

CLIENT_URL=http://localhost:5173

CLOUDINARY_CLOUD_NAME=your_cloud_name

CLOUDINARY_API_KEY=your_api_key

CLOUDINARY_API_SECRET=your_api_secret
```
